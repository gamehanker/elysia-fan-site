# elysia-fan-site
# 愛莉希雅應援小站

第五週生成式 AI 課程作業：使用 Vibe Coding 製作互動網頁。

## 網站功能

- 開場影片
- 角色介紹
- 心動相簿
- 圖片收藏
- 互動應援
- 應援宣言卡
- localStorage 儲存收藏與應援紀錄
- 支援電腦與手機瀏覽

## 線上網站

https://gamehanker.github.io/elysia-fan-site/

## 使用技術

- HTML
- CSS
- JavaScript
- GitHub Pages

## 開發方式

先透過 AI 討論網站規格，再利用 Vibe Coding 產生與修改網頁。
完成初版後，依照實際測試結果持續調整圖片裁切、文字內容與互動功能。

## 備註

本網站為非官方粉絲作品，僅作為課程學習與展示用途。
